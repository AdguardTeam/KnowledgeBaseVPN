This section explains how to install AdGuard VPN for Linux, sign in, connect to a server, and set it up on a router.

- [Installation and removal](/adguard-vpn-for-linux/installation-and-setup/installation/)

    Install AdGuard VPN CLI from the release, beta, or nightly channel and remove it if needed.

- [Login, connection, and update](/adguard-vpn-for-linux/installation-and-setup/login/)

    Log in to your AdGuard account, connect to a server, and check for updates.

- [Setting up on a router](/adguard-vpn-for-linux/installation-and-setup/setting-up-on-a-router/)

    Install AdGuard VPN CLI on a Keenetic, OpenWRT, Asuswrt-Merlin, or MikroTik router.
