These articles explain the features available in AdGuard VPN for iOS. Choose the topic you want to learn more about.

- [Exclusions](/adguard-vpn-for-ios/features/exclusions/)

    Manage the VPN connection for specific websites, add domains manually or from popular-service lists, and import or export exclusion lists.

- [Saved locations](/adguard-vpn-for-ios/features/saved-locations/)

    Save the server locations you use often and find them quickly in the *Saved* tab.

- [General settings](/adguard-vpn-for-ios/features/general-settings/)

    Choose a DNS server, change the theme, enable Kill Switch, and allow sending technical and interaction data.

- [Advanced settings](/adguard-vpn-for-ios/features/advanced-settings/)

    Learn about operating modes, logging level, log export, diagnostic data, and the VPN protocol.

- [Shortcuts](/adguard-vpn-for-ios/features/shortcuts/)

    Connect and disconnect from the Home Screen, Control Center, a widget, or with Siri.

- [Automation](/adguard-vpn-for-ios/features/automation/)

    Set up AdGuard VPN to turn on or off automatically for specific apps or Wi-Fi networks.
