These articles explain the features available in AdGuard VPN for Mac. Choose the topic you want to learn more about.

- [Exclusions](/adguard-vpn-for-mac/features/exclusions/)

    Manage the VPN connection for specific websites and apps, add services from popular lists, and import or export exclusion lists.

- [Saved locations](/adguard-vpn-for-mac/features/saved-locations/)

    Save the server locations you use often and find them quickly in the *Saved* tab.

- [Statistics](/adguard-vpn-for-mac/features/statistics/)

    See detailed information about traffic consumed by location and app.

- [App settings](/adguard-vpn-for-mac/features/app-settings/)

    Enable Kill Switch, auto-update, launch at login, and auto-connect, change the theme, and configure DNS servers.

- [Advanced settings](/adguard-vpn-for-mac/features/advanced-settings/)

    Learn about logging level, hiding the menu bar icon, the VPN protocol, and the IPv6 interface.
