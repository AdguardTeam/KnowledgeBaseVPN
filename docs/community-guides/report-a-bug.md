---
title: How to report a bug
sidebar_position: 4
---

If you spot a bug in AdGuard VPN or just want to share your suggestion with our developers, let us know. The preferred way to do it is GitHub:

1. Go to [GitHub](https://github.com/AdguardTeam/) and find the repository for the product you are using.
1. Check the existing issues to make sure the problem hasn’t been reported yet.
1. Create a new issue and describe the bug or feature request in detail.

If you want to support the implementation of a new feature or bugfix, you can vote for it on GitHub — just react with some emoji.

You can also use other channels:

- Find us on [social media](https://adguard-vpn.com/discuss.html). This is not the most efficient way to discuss technical matters, but we’ll always try to be helpful.

- Email our support team from the Support tab in the app or write directly to [support@adguard.com](mailto:support@adguard.com).
