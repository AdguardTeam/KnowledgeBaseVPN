These articles explain the features available in AdGuard VPN for Windows. Choose the topic you want to learn more about.

- [Exclusions](/adguard-vpn-for-windows/features/exclusions/)

    Manage the VPN connection for specific websites and apps, import or export exclusion lists, and exclude subnets.

- [Saved locations](/adguard-vpn-for-windows/features/saved-locations/)

    Save the server locations you use often and find them quickly in the *Saved* tab.

- [Statistics](/adguard-vpn-for-windows/features/statistics/)

    See detailed information about your data usage by location and app.

- [App settings](/adguard-vpn-for-windows/features/app-settings/)

    Set the app language, enable Kill Switch, auto-update, launch at startup, auto-connect, and configure DNS servers.

- [Advanced settings](/adguard-vpn-for-windows/features/advanced-settings/)

    Learn about operating modes, logging level, post-quantum cryptography, the VPN protocol, WinTun, and IPv6.
