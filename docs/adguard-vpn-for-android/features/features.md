These articles explain the features available in AdGuard VPN for Android. Choose the topic you want to learn more about.

- [Exclusions](/adguard-vpn-for-android/features/exclusions/)

    Manage the VPN connection for specific websites and apps, add domains manually or from built-in lists, and use the VPN selectively.

- [Saved locations](/adguard-vpn-for-android/features/saved-locations/)

    Save the server locations you use often and find them quickly in the *Saved* tab.

- [General settings](/adguard-vpn-for-android/features/general-settings/)

    Launch the app at system startup, choose a DNS server, enable Kill Switch, and change the theme.

- [Advanced settings](/adguard-vpn-for-android/features/advanced-settings/)

    Learn about operating modes, post-quantum cryptography, logging level, and diagnostic options.

- [Low-level settings](/adguard-vpn-for-android/features/low-level-settings/)

    Explore advanced options such as the VPN protocol, IPv6 interface, MTU, and proxy server port.
